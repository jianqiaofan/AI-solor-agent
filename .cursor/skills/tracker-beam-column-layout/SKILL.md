# 跟踪支架立柱与主梁布置

计算主梁中心线，再沿这根主梁布置驱动立柱和非驱动立柱。

认识构件种类时先读 qizhuo30-tracker。间距、长度和坐标只用本节规则和当次输入，不从产品构成反推。

截面、荷载、壳单元、内力和应力比不在这里做。

## 坐标

单位为 mm。Z 轴为高度，地面为 0，地面以上为正，地面以下为负。主梁中心线沿 Y 轴，X 保持为 0。中心线是水平的，两端 Z 相同。

- `h`：主梁中心线高度，也是立柱上端高度
- `L`：主梁长度
- 主梁起点：`(0, 0, h)`
- 主梁终点：`(0, L, h)`

立柱是竖线。下端 `(0, y, 0)`，上端 `(0, y, h)`。下端在地面，不伸到地面以下。

## 输入

从当次设计案例的 `geometry` 读取，缺一则停下并说明缺哪一项：

- `module_length_mm`：组件长度
- `module_width_mm`：组件宽度
- `ground_clearance_mm`：最小离地高度
- `arrangement_columns`：沿主梁的组件布置，例如 `22/22`

角度不读取 `tilt_angle_deg`。本规则里的倾角固定为 60°。

## 主梁高度 h

```text
h = 0.5 * module_length_mm * cos(60°) + ground_clearance_mm
```

`cos` 的自变量是角度。60° 是本规则的固定倾角。

## 主梁长度 L

组件间隙统一为 20 mm。`arrangement_columns` 里每个 `/` 是一处驱动（减速机、马达），该处间隙为 500 mm。

把字符串按 `/` 切开。每一段必须是正整数，表示这一段的组件块数 `n`。段数为 `k` 时，驱动有 `k - 1` 处。

```text
L = 各段 n * (module_width_mm + 20) 之和 + (k - 1) * 500
```

每块组件按 `(module_width_mm + 20)` 计入，不要改成段内只有 `n - 1` 个间隙。

`22/22` 的展开是：

```text
L = 22 * (module_width_mm + 20) + 500 + 22 * (module_width_mm + 20)
```

`11/22`、`22/22/22` 用同一条规则。字符串无法切成一段或多段正整数时，停下并说明，不要另设长度。

## 驱动立柱

每一个 `/` 一根驱动立柱。各段块数为 `n1…nk`，`pitch = module_width_mm + 20`。第 `i` 根从 1 计：

```text
y = (n1 + … + ni) * pitch + (i - 1) * 500 + 250
```

这是该处 500 mm 间隙的中点。`22/22` 只有一根，`y = 22 * pitch + 250`。

`y` 不圆整，也不挪到 100 的倍数。没有 `/` 就没有驱动立柱。

## 间距和悬挑

驱动立柱和非驱动立柱按 `y` 排成一列。相邻间距是后一根的 `y` 减前一根的 `y`。间距必须落在 7200 mm 到 9000 mm，含 7200 和 9000。驱动立柱参加这列间距，不在同一 `y` 再放一根立柱。

起点侧悬挑是第一根立柱的 `y`。终点侧悬挑是 `L` 减最后一根立柱的 `y`。两端各自落在 900 mm 到 1500 mm，含 900 和 1500。悬挑从主梁端点向内量，不把 `L` 加长。悬挑不必是 100 的倍数。

每一段内部各档用同一个间距。不同段的间距尽量相同；在仍然同样接近时，间距再尽量取 100 的整数倍。

硬性范围放不下时停下，写出这段的长度，以及卡在间距还是悬挑。不要放宽 7200–9000 或 900–1500，也不要移动驱动立柱。

## 非驱动立柱

用驱动立柱把主梁分成几段：起点到第一根驱动立柱、相邻驱动立柱之间、最后一根驱动立柱到终点。先列出每段可行的档数，再按下一节选定一组。

**驱动立柱之间。** 距离 `S` 固定。正整数档数 `s` 需满足 `7200 ≤ S / s ≤ 9000`，间距 `d = S / s`。`s = 1` 表示两根驱动立柱直接相邻，中间不加立柱。没有这样的 `s` 就停下。这里的 `d` 由 `S` 等分得到，不改成 100 的倍数。

**起点到第一根驱动立柱。** 距离为 `E`。档数 `s` 从 0 试到 `floor((E - 900) / 7200)`。

- `s = 0` 只在 `900 ≤ E ≤ 1500` 时可行。悬挑就是 `E`，这段不加非驱动立柱，第一根就是这根驱动立柱。
- `s ≥ 1` 时，间距必须落在

```text
I = [max(7200, (E - 1500) / s), min(9000, (E - 900) / s)]
```

`I` 的下端不超过上端才可行。选定 `d` 后，悬挑 `o = E - s * d`。非驱动立柱的 `y` 为 `o, o+d, …, o+(s-1)*d`。

**最后一根驱动立柱到终点**用同一套档数和区间，`E` 改为 `L` 减这根驱动立柱的 `y`。非驱动立柱的 `y` 为 `D+d, D+2d, …, D+s*d`，`D` 是这根驱动立柱的 `y`。

**没有驱动立柱。** 整根主梁是一段。档数 `s` 从 1 试到 `floor((L - 1800) / 7200)`。间距必须落在

```text
I = [max(7200, (L - 3000) / s), min(9000, (L - 1800) / s)]
```

`I` 的下端不超过上端才可行。两端悬挑都取 `(L - s * d) / 2`。立柱 `y` 为 `o, o+d, …, o+s*d`，最后一根落在终点侧悬挑之前。

若 `L` 在 1800–3000，并且没有任何 `s ≥ 1` 可行，只放一根非驱动立柱，`y = L / 2`。`L` 小于 1800，或大于 3000 但没有可行档数时，停下。

## 选定档数和间距

先列出各段可行档数的每一种组合。对一种组合，用下面的方法得到具体间距，再只保留一个组合。

比较时按这个顺序，前面已经分出优劣就不再看后面：

1. 全部档距里，最大间距减最小间距，越小越好。`s = 0` 的段没有档距，不参加比较。
2. 间距恰好是 100 的整数倍的档越多越好。除以 100 的余数在 0.001 mm 以内视为整除。
3. 起点侧悬挑与 1200 mm 的偏差，加上终点侧悬挑与 1200 mm 的偏差，越小越好。
4. 仍相同，取起点侧悬挑较小的；再相同，取较小的间距。

一种档数组合里的间距这样取：

- 驱动立柱之间只能用 `S / s`。
- 端部间距必须落在该档数的 `I` 里。若干段的 `I` 有公共部分时，这些段用同一个间距。公共部分里有 100 的整数倍时，只在这些倍数里再用第 3、4 条选择；没有整数倍时，也用第 3、4 条在公共部分里选择。
- 公共部分为空时，每段取自己区间里最靠近其他段间距的端点。不要为了凑 100 的倍数把间距拉开。
- 没有驱动立柱时，各档本来相同，只在 `I` 里按上面的公共部分规则选一个 `d`。

两端都向驱动立柱之间的间距看齐。某一端的 `I` 容纳得下那个间距，该端就用它；容纳不下，就用该端 `I` 里最接近它的值。

## 输出

代入当次数值，先写主梁，再按 `y` 从小到大写立柱。坐标保留计算所得的毫米值，不另做圆整。

```text
h = 0.5 * {module_length_mm} * cos(60°) + {ground_clearance_mm} = {h} mm
L = {展开式} = {L} mm
主梁起点 (0, 0, {h}) mm
主梁终点 (0, {L}, {h}) mm

驱动立柱 {i}
y = {展开式} = {y} mm
下端 (0, {y}, 0) mm
上端 (0, {y}, {h}) mm

立柱
序号  类型    下端              上端              与上一根的间距或本侧悬挑
1     非驱动  (0, {y}, 0) mm    (0, {y}, {h}) mm  起点侧悬挑 {o1} mm
2     非驱动  (0, {y}, 0) mm    (0, {y}, {h}) mm  间距 {d} mm
…
末    驱动    (0, {y}, 0) mm    (0, {y}, {h}) mm  间距 {d} mm，终点侧悬挑 {o2} mm
```

每一档间距写明是不是 100 的整数倍。有一段无法同时满足间距和悬挑时，说明冲突，不补一根到范围外的立柱。

## 完成条件

主梁起点、终点、`h`、`L` 已经给出。每一根驱动立柱都在对应 500 mm 间隙的中点。非驱动立柱已按选定间距放入，或已说明哪一段放不下。相邻间距都在 7200–9000，含端点。两端悬挑都在 900–1500，含端点。

## 不做的事

- 不生成 SAP2000 模型，不建线单元或壳单元
- 不预设截面，不从截面库选型，不比较单米重量
- 不加风荷载、雪荷载、组件自重，不做荷载组合
- 不计算内力，不校核应力比
